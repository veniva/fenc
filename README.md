# Fenc - File Encrypter — project website

Public website and supporting resources for File Encrypter, an app for
password-based AES-256-GCM file encryption and decryption.

This app is distributed as closed-source software as part of our approach to security, aiming to reduce the exposure of its implementation details, potentially making the discovery of exploitable vulnerabilities more difficult, and increase the cost and effort required for potential attackers. While this approach does not guarantee security, it may help reduce certain risks associated with publicly accessible source code.

We are particularly concerned that advances in AI technologies will increasingly enable malicious actors to discover and exploit previously unknown vulnerabilities in open-source applications with each new feature release, potentially leading to zero-day attacks before these vulnerabilities are reported or patched.
